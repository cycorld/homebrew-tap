# Homebrew Tap for cycorld

Custom Homebrew tap for [MarkPad](https://github.com/cycorld/markpad) and other applications.

## How do I install these formulae?

### MarkPad

```bash
brew install --cask cycorld/tap/markpad
```

Or tap first:

```bash
brew tap cycorld/tap
brew install --cask markpad
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
